# ✍️ Corretor de Texto Inteligente

Ferramenta web para correção e reescrita de textos com suporte a diferentes tons de comunicação (Informal, Equilibrado e Formal). O projeto consome uma API externa para processamento linguístico e oferece uma interface responsiva com modo escuro.

## 🚀 Acesse o Projeto

🔗 **[CLIQUE AQUI PARA ACESSAR](https://solamdev.github.io/site-de-corrigir-texto/)**

## 🛠️ Funcionalidades

-   **Ajuste de Tom:** Alterne entre estilos *Informal*, *Equilibrado* e *Formal*.
-   **Correção via API:** Processamento de texto em tempo real utilizando endpoint REST.
-   **UX Aprimorada:** Botões de copiar/colar integrados, feedback visual de carregamento e notificação animada ao copiar.
-   **Dark Mode:** Alternância de temas com persistência da preferência via `localStorage`.
-   **Responsividade:** Layout adaptável para dispositivos móveis e desktop.
-   **Acessibilidade:** Suporte a envio via tecla `Enter` e estados visuais para botões desabilitados.

## 🏗️ Tecnologias

-   **Frontend:** HTML5 Semântico, CSS3 (Variáveis, Flexbox, Keyframes), JavaScript Vanilla (ES6+).
-   **API:** Integração REST (`fetch`) para serviço de correção e reescrita.
-   **Armazenamento:** `localStorage` para persistência de tema.


## ⚙️ Como Executar Localmente

1.  Clone este repositório:
    ```bash
    git clone <https://github.com/solamdev/site-de-corrigir-texto>
    ```
2.  Navegue até a pasta do projeto.
3.  Abra o arquivo `index.html` em seu navegador.

> **⚠️ OBS:** A funcionalidade de correção depende da disponibilidade da API externa configurada no `index.js`.
